# Radicale IDP

[![Test](https://github.com/Kozea/Radicale/actions/workflows/test.yml/badge.svg?branch=master)](https://github.com/Kozea/Radicale/actions/workflows/test.yml)
[![Coverage Status](https://coveralls.io/repos/github/Kozea/Radicale/badge.svg?branch=master)](https://coveralls.io/github/Kozea/Radicale?branch=master)

Radicale is a small but powerful CardDAV (contacts) server. For the complete documentation, please visit
[Radicale master Documentation](https://radicale.org/master.html).

Radicale IDP extends Radicale by including (interdependent) privacy protection features. It is based on the results presented in a scientific [publication](https://www.usenix.org/conference/usenixsecurity25/presentation/niksirat). It is developed by the [University of Lausanne](https://www.unil.ch) (UNIL) and the [University of Applied Sciences and Arts Western Switzerland](https://heig-vd.ch) (HES-SO). It is partially funded by the [Hasler Foundation](https://haslerstiftung.ch/en/welcome-to-the-hasler-foundation/).
